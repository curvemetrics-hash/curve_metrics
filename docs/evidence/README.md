# Evidence to keep

Keep dated, original records as the work happens. Do not recreate them later.

| Evidence | Where | When |
|---|---|---|
| Signed licence agreement | `docs/evidence/agreement/` | Before work starts |
| Baseline record | `docs/metrics-and-results.md` and `docs/templates/baseline-record.md` | Before the build |
| Commit and review history | The repository itself (do not rewrite history) | Throughout |
| Pipeline run logs | `docs/evidence/pipeline-runs/` (exports) | Weekly |
| Test outputs | `docs/evidence/test-runs/` | Each run. Save the real output; never write a result that no run produced |
| Weekly check-ins | `docs/evidence/checkins/` | Weekly |
| Review note and Continuation Decision | `docs/evidence/review/` | At the review |
| Signed letters | `docs/evidence/letters/` | When issued |

Never store secrets, credentials or personal data in this folder.
