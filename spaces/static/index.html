Continuous Compliance Matrix

Baseline Controls (14)

Determines formal compliance: Default-deny network policies, no open cluster-admin bindings, quota constraints, resource limits, ownership tags, S3 public block, S3 versioning/encryption, SQS KMS, CloudWatch log retention, and scoped IAM roles.

Workload Security

Detects privileged containers, host access escapes, root user execution, dangerous Linux capabilities, unpinned mutable image tags, plaintext secrets in specs, missing liveness/readiness probes, and unbounded resource requests.

Exposure & Access

Flags NodePort/LoadBalancer exposure, unencrypted ingress, permissive network policies, wildcard IAM permissions, unauthorised secret read permissions, and manual cluster-admin bindings.

Drift & Runtime Faults

Surfaces out-of-band policy mutations, broken IRSA bindings, pod CrashLoopBackOffs, pending workloads, replica starvation, namespace quota saturation, and Kubernetes warning events.

AWS Configuration

Deep inspection of S3 bucket policies, SQS dead-letter queues, automated Secrets Manager rotation, least-privilege IAM trust policies, cross-account boundaries, and wildcard actions.
